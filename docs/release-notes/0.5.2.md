Three mouse affordances that were missing: pinning a tab, opening one from the empty strip, and scrollbars
that stop sitting on top of the text.

### Pin a tab by clicking it

Pinning was only reachable three ways — the tab's right-click menu, `Alt+P`, or the command palette — none of
them a thing you could see. Hover a tab and a pin appears beside its ✕; click it to pin.

A **pinned** tab keeps its pin showing, and clicking it unpins. That matters more than it sounds: the pinned
row deliberately has no ✕ (a close target two pixels from a tab you meant to keep is how you lose it), so
until now there was no way out of that row with the mouse at all.

The pin is hollow when the tab is unpinned and filled when it is, so the shape carries the state rather than
just the colour. It appears only under the pointer, because a permanent mark on every tab would clutter a
strip that 0.5.0 spent effort narrowing — and it fades in rather than appearing, so the tab's width does not
change as you move across the strip.

Clicking the pin does **not** select the tab. Pinning something you are not currently working in is an
ordinary thing to want, and having the editor jump to it would be a surprise.

### Double-click the empty strip for a new tab

As every browser does. A double-click on a tab itself still renames it, as before.

### Scrollbars no longer cover text

A scrollbar was drawn on top of the content instead of beside it, so in **Settings** it ran straight through
the `pt` label next to both font-size fields and crowded every checkbox in the list. It now takes a column of
its own.

The same thing was happening in four other places, and all of them are fixed:

- **The cell inspector** — the worst of them. Text wraps to the full width there, so the bar covered the last
  characters of every line it crossed, in the one panel whose whole job is showing you a value in full.
- **The keyboard shortcuts window**, whose rows end in the shortcut itself.
- **The release notes dialog** — this one, in fact.
- **The error details dialog**, where a stack trace is read to the end of its lines.

Short popups that scroll a little — the connection dialog's options list, the import review — are unchanged:
a permanently visible bar on a small popup is heavier than the problem it solves.

### Upgrading

Nothing to do. No settings, projects or keybindings change.

### Known limitations

Unchanged from 0.5.0: the installers are unsigned, so Windows SmartScreen warns on first run; there is no
macOS package; and syntax colouring is verified by eye rather than by tests.
