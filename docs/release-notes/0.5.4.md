One fix and one addition, both in the connection editor's environment row.

### The preset buttons re-label the connection

Clicking **Local** and then **Production** left the connection still reading `local`, in production red. The
label was only ever filled when the box was empty, so the first preset you clicked won and every one after it
changed nothing but the colour — on the one field whose whole job is to tell you which server you are about to
run against.

A preset now sets the label as well as the hue, and knows when not to. A label you typed yourself —
`staging-eu`, `prod-eu-west` — is yours and survives; only the colour follows the click. An empty box, or one
still holding another preset's own name (`local`, `staging`, `production`), is overwritten.

**Production** still ticks "confirm before running writes" for you, and still does not untick it when you move
back to a lesser preset. Dropping a write guard is a decision, not a side effect of a click.

### The environment colour can be picked

The hue was hex-only: you typed `#E5484D` or you had a grey connection. The swatch beside the field is now the
button of a colour picker — spectrum, sliders, palette, and a hex field of its own — and it sits next to the
hex box, because it is the same value by another route. Typing a hex still works, and the two stay in step
whichever one you use.

The swatch keeps showing what will actually be saved rather than what the picker happens to hold, so a blank
or half-typed hex reads as the neutral grey it will resolve to.

### Upgrading

Nothing to do. No settings, projects or keybindings change.

### Known limitations

Unchanged from 0.5.0: the installers are unsigned, so Windows SmartScreen warns on first run; there is no
macOS package; and syntax colouring is verified by eye rather than by tests.
