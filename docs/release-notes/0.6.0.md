A SQL formatter, an EXPLAIN plan viewer, and a crash that could take the app down with your unsaved buffer.

This one also carries everything 0.5.4 was meant to. That release was tagged and described but shipped no
packages at all, so no installed copy ever saw it — if Bearing has been telling you 0.5.3 is the latest
version, that is why, and it was right.

### Format SQL

**Ctrl+Shift+F**, or the editor's new right-click menu. Layout only: it never reorders, adds or removes a
token, and never changes a literal or an identifier.

That is a property of how it is built rather than a promise. It walks the token stream and only ever chooses
the whitespace *between* tokens, so a `$$ … $$` body comes through byte for byte — it is one token — and
operators like `#>>`, `||` and `<@` cannot be pulled apart. Comments survive for the same reason. And every
result is checked before you see it: the output is re-lexed and compared token by token against the input,
and anything beyond whitespace and keyword case makes it hand your SQL back untouched and tell you why.

SELECT, INSERT, UPDATE, DELETE, CTEs, set operations, subqueries, joins and CASE are laid out, as are
CREATE TABLE and the CREATE FUNCTION envelope. A function *body* is left exactly as written — it is one
token, and `LANGUAGE plv8` is JavaScript, `plpython3u` is Python. Any other statement shape comes back
byte for byte: no rules for it means no change to it, never a guess.

SQL that does not parse is not formatted at all.

**Settings ▸ Editor** carries keyword case (UPPERCASE, lowercase, or leave as typed) and indent width. Both
apply on the next Ctrl+Shift+F, not the next restart.

### Explain a statement, and see where its time went

`EXPLAIN` and `EXPLAIN ANALYZE` for the statement under the caret — **Ctrl+Shift+E** and **Ctrl+Alt+E**, a
toolbar button beside Run, and both in the Query menu. The plan is a tree with a proportional self-time bar
on every row, so the tree is also the chart.

### A crash that predated the formatter

Completion parses whatever is in the editor on every keystroke, and past about two hundred levels of nested
parentheses that parse overflowed the stack. A stack overflow cannot be caught in .NET: the process dies
and takes the unsaved buffer with it. Pasting a deeply nested expression was enough.

Parsing now runs with room for roughly six thousand levels, and anything past a thousand is declined rather
than attempted — the choice there is between declining and crashing, so it declines.

### Completion in the write statements

`update contracts set pay…` offered nothing: no table after `update`, `insert into` or `delete from`, no
column in a `SET`, and an UPDATE's `WHERE` completed against every table in the database rather than the one
being written. All three are fixed, and only the target's own columns are offered where only they are legal.

### Copy a table with the query that produced it

`Copy as ▸` gains **Table with the query that produced it** — the same HTML table as the existing entry, with
the statement in a full-width row above the headers. Two menu entries rather than a setting, because the
choice is per-paste.

### Scroll the tab strip to switch tabs

The wheel over either tab row steps the selection instead of panning. No wrap at the ends — a wheel
overshoots, and being teleported to the other end mid-gesture is how you lose the tab you were hunting for.
**Shift+wheel** still pans. Trackpad fractions bank into whole notches, so one swipe is a couple of tabs
rather than thirty.

### Smaller things

- **A failed statement's message can be selected and copied.** It was plain text before, so an error had to
  be retyped into a search box.
- **A ✕ on the results pane.** It could only be dismissed with Ctrl+R, which is fine once you know and
  invisible until then.
- **Ctrl+M** toggles the side pane, alongside Ctrl+B — the DBeaver reflex.
- **A right-click menu in the editor**: run, explain, the clipboard three, format, select statement, toggle
  comment, fold all. Every one of those existed and was reachable only by a gesture you had to already know.
  A right-click outside the selection puts the caret where you clicked first, so what runs is the statement
  you are pointing at.
- **The environment colour can be picked** rather than typed as hex, and a preset button now re-labels the
  connection instead of only recolouring it. A label you wrote yourself is yours and survives. *(Meant for
  0.5.4, which never shipped.)*

### Upgrading

Nothing to do. No settings, projects or keybindings change.

If you are on 0.5.3, this is the next version you can get — 0.5.4 never had packages to download, and its
tag and release page have been removed so the history reflects what was actually shipped.

### Known limitations

Unchanged from 0.5.0: the installers are unsigned, so Windows SmartScreen warns on first run; there is no
macOS package; and syntax colouring is verified by eye rather than by tests.

The formatter has no rules for most DDL and leaves it untouched, by design — see above.
