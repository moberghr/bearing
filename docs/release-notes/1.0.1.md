**Completion was dead in the whole of 1.0.** No suggestions while typing, nothing on Ctrl+Space, on every
connection and both engines. This release is that one fix.

### What happened

1.0 added Microsoft SQL Server, and with it a question completion has to answer on every keystroke: which
grammar is this tab written in? The engine asked it from the thread it runs the parse on — and the answer
comes from the editor's own window, which only the interface thread is allowed to touch. So every request
failed before it read a single character.

It failed quietly, which is why 1.0 shipped this way. Completion is built never to interrupt what you are
typing, so a fault in it goes to the crash log and nothing else: the popup simply never appeared. The same
code now resolves the grammar before handing the text to the parser, which is the one place the question can
be asked safely.

Two tests hold it there, and they need to be two. One pins where the engine asks; the other types
`select * from d` into a real window and requires a real popup with rows in it, because the engine's own
test cannot see a window and so cannot fail for this reason. Each was checked against the broken code
before being kept.

A failing completion also wrote its full diagnostic to the crash log **once per keystroke** — 38 copies of
one stack trace in four minutes, on a path that runs while you type. It is recorded once per run of failures
now, and again if it ever comes back after a success.

### Upgrading

Nothing to do. No settings, projects or keybindings change.

### Known limitations

Unchanged from 1.0.0 — the installers are unsigned, macOS is Apple Silicon only, and the SQL Server caveats
listed there all still apply.

One worth stating because it looks like the bug above and is not: **completion needs the catalog to have been
read.** A tab pointed at a connection you have not connected this session has no schema to suggest from, and
offers nothing until you connect it or run a statement on it. Connecting the tab is enough; nothing needs
re-typing.
